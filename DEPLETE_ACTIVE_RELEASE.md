# Deplete participates in web predictions

The web panel uses 80% primary PF smoothed probability and 20% independent Deplete MC probability. EV, direction and existing V4 display decisions are computed from the blended report. Each final-score input resets both models; this does not reconstruct an entire observed shoe or add unseen card evidence.

Original V4 thresholds and uncertainty floors remain. There is no validated betting edge and bet_allowed remains false. Deplete failure or a missing module preserves the primary PF report and displays a fallback message. Existing shadow API stays available for comparisons.

All 100 score pairs: primary B36/P24/SKIP40; active blend B32/P22/SKIP46. Previous frozen million-scenario synthetic validation did not establish improved hit rate or commission-adjusted return. Activation is the user-requested model choice, not a validated performance promotion. The million-case JSON remains unchanged and promotion_eligible remains false.
