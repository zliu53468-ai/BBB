# 網頁單局精確推估：100 萬組驗證報告

此報告使用合成牌局，不是現場歷史牌局回測，也未證明實戰勝率提升。

## 方法

- 100 萬個獨立情境，每個情境從完整八副牌發當局，再預測下一局，共 200 萬手。
- 只將當局閒、莊最終點數交給模型；先固定預測，再發下一局。
- 精算引擎枚舉 339,400 條合法牌張路徑，合併為 6,958 種扣牌組成；100 種點數是完整輸入空間，不是訓練樣本數。
- 另用不同實作的實體牌組抽牌器驗證，種子 20261104；沒有用驗證結果調整門檻。

## 結果

| 方法 | 出手／參考局數 | 非和局命中率 | 扣佣後每次出手收益 |
|---|---:|---:|---:|
| 舊版顯示訊號 | 597,409 | 50.1384% | -1.1662% |
| 新版正式顯示 | 0 | 不適用（沒有出手） | 不適用 |
| 新版相對 EV 方向（非出手訊號） | 1,000,000 | 50.6399% | -1.1332% |
| 固定莊基準 | 1,000,000 | 50.6399% | -1.1332% |
| 固定閒基準 | 1,000,000 | 49.3601% | -1.1581% |
| 新版方向／相同舊版出手局 | 597,409 | 50.6534% | -1.1094% |

新版正式顯示沿用 V4 門檻，100 種輸入全部觀望。若只比較相對 EV，100 種輸入都選莊，與固定莊基準相同，不能宣稱有新增優勢。

各點數分組的最大機率誤差為 2.449 個標準誤；條件分布卡方值 167.607（200 自由度）。

舊版 EV 與精算值的平均絕對差為 0.4465 個百分點，最大差 1.6647 個百分點。這是模型計算差異，不是實戰收益改善。

## 限制

起始牌組是完整八副牌假設，不代表現場殘牌。沒有觀測現場牌張、換靴、棄牌及規則差異。100 萬組結果能驗證這個假設下的計算一致性，不能保證適用任何實際牌桌。

相同舊版出手局上的收益差之 95% 區間包含零，未顯示統計上明確的收益改善。和局退回本金，命中率分母排除和局；出手比例以全部情境為分母。
